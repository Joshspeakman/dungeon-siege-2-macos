# Dungeon Siege II for Apple Silicon Macs

Work in progress: Dungeon Siege II (GOG 2.3), statically recompiled from the user's own copy into native arm64 code,
as [dungeon-siege-macos](https://github.com/Joshspeakman/dungeon-siege-macos) does for Dungeon Siege 1. Nothing from
the game is in this repository; the build regenerates everything locally from the user's copy.

Status and plan: [docs/PLAN.md](docs/PLAN.md).
